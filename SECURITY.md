# Security Policy

GalibierHub takes security issues seriously. Please report vulnerabilities privately so they can be fixed before public disclosure.

## Reporting a Vulnerability

Prefer a GitHub Security Advisory at:

`https://github.com/Helloxiaolaodi/GalibierHub/security/advisories`

You can also contact the project maintainer directly at:

`yanglun2019@126.com`

Please include:

- affected URL, route, or endpoint
- relevant versions or commit information
- steps to reproduce
- observed impact
- any suggested remediation, if available

Do not open a public issue for an active vulnerability.

## Disclosure Process

The maintainers will acknowledge reports within three business days. We follow coordinated disclosure and normally provide a fix window before public details are published. If a report is validated, the reporter may be acknowledged on the site's `/acknowledgments` page after the issue is resolved.

## Scope

- GalibierHub application code in this repository
- public API routes and static assets served by the site
- Supabase, Cloudflare, Vercel, and Hugging Face integration points documented in the repository

## Safe Harbor

Coordinated research performed in good faith under this policy is welcome. Do not test in ways that affect other users, destroy data, or access private production data outside the scope of the report.
